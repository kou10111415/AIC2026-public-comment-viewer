# AIC2026：パブリックコメント結果ビューア

第7次エネルギー基本計画のパブリックコメント1,233要求の最新結果を閲覧する静的ビューアです。

共有URLを開くと日本語ビューアを直接閲覧できます。要求要約、判定理由、引用、比較本文の英訳を用意しています。英訳は参照用で、判定・信頼度・要求ID・イベントID・段落IDを維持しています。

全ページ上部の1段目で `JP / EN`、2段目で `ビューア / 指示文`（`Viewer / Prompts`）を切り替えられます。言語を切り替えても、ビューアまたは指示文というページ種別を保持します。

日本語の分析データと表示構成を保持しています。単一条件しかない「判定方法」「対象文書・版間」「資料種別」の選択欄と不要な説明を取り除いています。検索、判定による絞り込み、ページ送り、差分・引用表示、段落番号は維持しています。

## ページ

- `index.html`：日本語ビューア（最初の選択ページは削除）
- `japanese.html`：同じ日本語ビューアの既存リンク互換用URL
- `english.html`：英語ビューア
- `prompts-ja.html`：指示文の日本語原文
- `prompts-en.html`：プロンプトの英語参考訳
- `prompts/`：システム指示文、入力テンプレート、出力スキーマ

上段では案と最終案の本文を色付けせずに表示し、下段で変更箇所を確認できます。英語版の下段は、日本語原文の変更に対応する既存の英文だけをハイライトします。独立した訳し分けや日本語の表記整理だけを、英語の内容変更として強調しません。

判定の選択肢には、このビューアの新旧比較で使用されている区分だけを表示します。

公開対象はパブリックコメントのみです。
