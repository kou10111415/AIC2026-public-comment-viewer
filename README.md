# AIC2026：パブリックコメント結果ビューア

第7次エネルギー基本計画のパブリックコメント1,233要求の最新結果を閲覧する静的ビューアです。

日本語・英語の言語選択ページから閲覧できます。要求要約、判定理由、引用、比較本文の英訳を用意しています。英訳は参照用で、判定・信頼度・要求ID・イベントID・段落IDを維持しています。

全ページ上部の1段目で `JP / EN`、2段目で `ビューア / 指示文`（`Viewer / Prompts`）を切り替えられます。言語を切り替えても、ビューアまたは指示文というページ種別を保持します。

日本語の分析データと表示構成を保持しています。単一条件しかない「判定方法」「対象文書・版間」の選択欄とその説明のみ取り除いています。検索、判定による絞り込み、ページ送り、差分・引用表示、段落番号は維持しています。

## ページ

- `index.html`：日本語 / English の選択
- `japanese.html`：日本語ビューア
- `english.html`：英語ビューア
- `prompts-ja.html`：最終プロンプトの日本語原文
- `prompts-en.html`：プロンプトの英語参考訳
- `prompts/`：システム指示文、入力テンプレート、出力スキーマ

要求抽出・独立検証の指示文は、それぞれ1,011入力の保存済み実行記録とハッシュ照合しています。改訂対応判定の指示文は、1,233要求の保存済み送信内容と照合済みです。英語の差分ハイライトは翻訳文同士の差分です。原分析の再実行はしていません。

公開対象はパブリックコメントのみです。
